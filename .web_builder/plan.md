## 架构与接口
- Astro 7.3.3 静态生成 + TypeScript + 原生 CSS + Markdown 内容集合。安装时审计发现 Astro 5.18.2 有未修复公告，选用当前修复版本；Node 24。
- `src/content.config.ts` 校验作品；`src/content/works/*.md` 是作品唯一注册表。
- `src/content/about.md` 为独立个人介绍；`src/data/site.ts` 保存站名与联系方式。
- `/` 精选首页，`/works/` 全作品，`/works/[slug]/` 详情，`/about/` 关于。
- 原始作品 `/demos/[slug]/index.html`，避免与详情路由冲突。
- 外链只允许 HTTP(S)，新标签打开；本地预览按点击加载，保留独立打开。
- 路径函数为所有内部 URL 添加部署 base；Pages 采用 Actions。
- 设计：近黑 #0B0D10、青蓝 #38BDF8；中文正文系统字体、英文自托管 Sora；亮暗主题与减少动态效果。
