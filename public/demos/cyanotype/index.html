命题
六张图版，六个自行生长的系统。没有一张图是预先画好的——墨的洇散、星的轨迹、纹的分裂、枝的分叉、声的触发，都在你打开这一页的此刻才被算出来，关掉就永远散了。
工艺
蓝晒（cyanotype）是十九世纪的接触晒印法：涂布铁盐的纸在日光下曝光，水洗后留下普鲁士蓝。它天生是负相的——受光处反而留白。这部图谱借了它的相：蓝为底，骨白为线。左上角的开关把整册翻回正片。
算法
墨山：中点位移分形生成远山，笔触由速度控制提按，数千枚半透明墨核作随机游走模拟洇散。
星槎：带软化半径的 N 体引力积分，碰撞按动量守恒合并。「八字」为 Chenciner–Montgomery 三体周期解的精确初值。
织理：Gray–Scott 反应扩散，两种虚构化学物在网格上互相追逐。
荒木：递归分枝，每株树有一组随机「基因」决定角度、收束比与扭曲。
水琴：脉冲环扫过石子时触发振荡器，音高由纵向位置决定——节奏是几何算出来的，不是谱出来的。
材料
单一 HTML 文件。零依赖、零外部请求：没有图片、没有网络字体、没有音频文件、没有框架。声音由 Web Audio 的振荡器合成，纹理由 SVG 湍流滤镜生成。断网也能完整运行。
操作
方向键翻版，1–6 直接跳版，空格切换正负片。每张图版都可以直接在画面上拖曳。
